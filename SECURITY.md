# Security Policy

## Reporting a Vulnerability

**Please don't disclose security issues publicly**: no public issues, pull requests, discussions or Discord messages.

Report them privately through GitHub: [**Report a vulnerability**](https://github.com/the-momentum/open-wearables/security/advisories/new) (Security tab → Advisories → Report a vulnerability). Only you and the maintainers see the report, and we discuss and track the fix there.

Please include:

- the affected version or commit,
- what an attacker can do and under which conditions,
- steps to reproduce or a proof of concept.

Once a fixed version is released, we publish the advisory, crediting you unless you ask us not to.
