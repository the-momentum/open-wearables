## Introduction

The Open Wearables React Native SDK (`open-wearables`) enables secure background synchronization of health data from **Apple HealthKit** (iOS), **Samsung Health**, and **Health Connect** (Android) to the Open Wearables platform.

The SDK is built with the [Expo Module API](https://docs.expo.dev/modules/module-api/), so it works in Expo projects as well as in bare React Native projects with Expo modules installed.

On iOS, the React Native SDK is a **wrapper around the [native iOS SDK](/sdk/ios)** (`open_wearables_ios_sdk`). On Android, it wraps the **[native Android SDK](/sdk/android)** (`open_wearables_android_sdk`). This means all the core sync logic — background execution, streaming uploads, secure storage, and retry mechanisms — is handled by the native implementations under the hood. The React Native layer provides a convenient TypeScript API for cross-platform apps.

## Features

- **Cross-Platform** - Single TypeScript API for iOS (HealthKit) and Android (Samsung Health, Health Connect)
- **Background Sync** - Health data syncs even when your app is in the background
- **Incremental Updates** - Only syncs new data using anchored queries
- **Secure Storage** - Credentials stored in iOS Keychain / Android EncryptedSharedPreferences
- **Dual Authentication** - Token-based auth with auto-refresh or API key authentication
- **Resumable Sessions** - Sync sessions survive app restarts
- **Wide Data Support** - Steps, heart rate, workouts, sleep, and 40+ data types
- **Provider Selection** - Choose between Samsung Health and Health Connect on Android

## Installation

<Warning>
  **Temporary setup.** The package is not published to npm yet, and its Android native dependency is only available through Maven Local. We're working on publishing the package to npm and serving the Android dependency from a public repository - steps 1 and 3 below will then become a plain `npm install`.
</Warning>

<Steps>
  <Step title="Install the package from GitHub">
    ```bash
    npm install github:the-momentum/open-wearables-react-native-sdk#<commit-sha>
    ```

    npm builds the package during install. Pin a commit so updates are deliberate. The package is imported as `open-wearables`.
  </Step>

  <Step title="Add the config plugin">
    Required for Expo projects - it sets the iOS HealthKit entitlements, `Info.plist` keys and background modes, and the Android Health Connect activity aliases. Set the Android `minSdkVersion` in the same file, which needs `expo-build-properties`:

    ```bash
    npx expo install expo-build-properties
    ```

    ```json app.json
    {
      "expo": {
        "plugins": [
          [
            "open-wearables",
            {
              "healthShareUsage": "Allow $(PRODUCT_NAME) to read your health data.",
              "healthUpdateUsage": "Allow $(PRODUCT_NAME) to write health data."
            }
          ],
          ["expo-build-properties", { "android": { "minSdkVersion": 29 } }]
        ]
      }
    }
    ```

    Bare React Native projects set these by hand - see [Expo and bare React Native setup](/sdk/react-native/integration#expo-and-bare-react-native-setup).
  </Step>

  <Step title="Android: publish the native SDK to Maven Local">
    ```bash
    git clone https://github.com/the-momentum/open_wearables_android_sdk
    cd open_wearables_android_sdk
    git checkout v0.11.2
    ./gradlew publishToMavenLocal
    ```

    This also installs the Samsung Health SDK the native SDK depends on. Then run `npx expo prebuild` in your app and add `mavenLocal()` as the **first** repository in `android/build.gradle`:

    ```gradle android/build.gradle
    allprojects {
      repositories {
        mavenLocal()
        // ...
      }
    }
    ```

    Repeat this on every machine that builds the app, including CI. `npx expo prebuild --clean` regenerates `android/`, so add `mavenLocal()` again afterwards.
  </Step>

  <Step title="Build and run">
    ```bash
    npx expo run:ios
    npx expo run:android
    ```

    Bare React Native: run `npx pod-install` before building for iOS.
  </Step>
</Steps>

## Quick Start

The minimal flow - see the [Integration Guide](/sdk/integration) for when to call what:

```ts
import OpenWearablesHealthSDK, { HealthDataType } from "open-wearables";

// Every app launch
OpenWearablesHealthSDK.configure("https://api.your-open-wearables.com");

// Once per user, with tokens from your backend
await OpenWearablesHealthSDK.signIn(userId, accessToken, refreshToken, null);

// Android only
OpenWearablesHealthSDK.setProvider("google");

await OpenWearablesHealthSDK.requestAuthorization([HealthDataType.Steps, HealthDataType.HeartRate, HealthDataType.Sleep]);
await OpenWearablesHealthSDK.startBackgroundSync(90);
```

## Events
Subscribe to native SDK events using the standard Expo module event emitter:

```TypeScript

  const subscription = OpenWearablesHealthSDK.addListener("onLog", ({ message }) => {
    console.log("SDK log:", message);
  });

  const authSub = OpenWearablesHealthSDK.addListener(
    "onAuthError",
    ({ statusCode, message }) => {
      console.error(`Auth error ${statusCode}:`, message);
    }
  );

  // Clean up
  subscription.remove();
  authSub.remove();

```

| Event         | Payload                                   | Description                            |
| ------------- | ----------------------------------------- | -------------------------------------- |
| `onLog`       | `{ message: string }`                     | Log messages emitted by the native SDK |
| `onAuthError` | `{ statusCode: number, message: string }` | Authentication errors                  |
